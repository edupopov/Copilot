# Prompts Técnicos

Prompts técnicos são utilizados para tarefas de **desenvolvimento de software**, **infraestrutura**, **arquitetura de soluções** e **troubleshooting**. São voltados para engenheiros, desenvolvedores e arquitetos.

## Categorias

### Código
Geração, revisão, refatoração e documentação de código em diversas linguagens.

### Scripts
Automação de tarefas com PowerShell, Bash, Python e outros.

### Arquitetura
Desenho e revisão de soluções, diagramas, decisões arquiteturais.

### Troubleshooting
Diagnóstico de erros, análise de logs e resolução de problemas.

## Dicas

- Forneça o contexto da linguagem, framework e versão utilizados
- Inclua o código existente ou o erro completo ao pedir troubleshooting
- Especifique os requisitos não-funcionais (performance, segurança, escalabilidade)
- Peça explicações junto com o código para facilitar revisões e aprendizado
