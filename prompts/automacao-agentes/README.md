# Prompts de Automação e Agentes (Copilot Studio)

Prompts voltados para a criação e configuração de **agentes personalizados** no Copilot Studio, automação de fluxos de trabalho e integração com sistemas corporativos.

## Cenários Cobertos

- Criação de tópicos e fluxos de conversação no Copilot Studio
- Definição de ações e integrações com APIs e conectores Power Platform
- Configuração de knowledge bases e fontes de dados
- Design de experiências conversacionais para usuários finais

## Exemplos disponíveis

| Arquivo | Cenário |
|---|---|
| [`exemplo-copilot-studio.md`](exemplo-copilot-studio.md) | Configuração de agente no Copilot Studio |
| [`exemplo-agente-customizado.md`](exemplo-agente-customizado.md) | Criação de copiloto personalizado para um domínio específico |

## Dicas

- Defina claramente o escopo e as limitações do agente
- Especifique as integrações necessárias (SharePoint, Dataverse, APIs externas)
- Documente os tópicos principais e as variações de intenção do usuário
- Inclua tratamento de fallback para perguntas fora do escopo
- Teste com cenários reais antes de publicar para produção
