# Prompts de Revisão e Padronização

Prompts voltados para **revisão de conteúdo**, **melhoria de texto** e **padronização de documentos** corporativos, mantendo consistência de tom, estilo e qualidade.

## Cenários Cobertos

- Revisão gramatical e de clareza em documentos técnicos e funcionais
- Adaptação de conteúdo para diferentes públicos (técnico, executivo, usuário final)
- Padronização de templates e documentação de projetos
- Melhoria de comunicados, e-mails e apresentações corporativas

## Dicas

- Forneça o texto original completo para revisão
- Especifique o público-alvo e o tom desejado (formal, técnico, acessível)
- Indique se quer manter o conteúdo fiel ao original ou se pode haver reformulações
- Peça uma versão comentada das mudanças sugeridas para facilitar a revisão
- Defina o guia de estilo corporativo a ser seguido quando disponível
