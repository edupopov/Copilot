# Exemplo: Sumarização de Documentos e Reuniões

## Cenário
Utilizar o Copilot para resumir documentos extensos, atas de reunião, relatórios e apresentações, extraindo os pontos mais relevantes de forma estruturada.

---

## Templates

### Resumo de Documento

```
Tipo de documento: [RELATÓRIO / ATA / CONTRATO / ARTIGO / OUTRO]
Público-alvo do resumo: [EXECUTIVO / TÉCNICO / GERAL]
Nível de detalhe: [ALTO NÍVEL (3-5 pontos) / MÉDIO (1 página) / DETALHADO (manter estrutura original)]
Foco especial em: [RISCOS / DECISÕES / AÇÕES / DADOS FINANCEIROS / OUTRO]

Resuma o documento abaixo:
[COLAR DOCUMENTO AQUI]
```

### Resumo de Reunião

```
Contexto da reunião: [OBJETIVO E PARTICIPANTES]
Data: [DATA]
Duração: [DURAÇÃO]

Transcrição / Notas da reunião:
[COLAR TRANSCRIÇÃO OU NOTAS AQUI]

Gere uma ata estruturada com:
1. Resumo executivo (3-5 linhas)
2. Decisões tomadas
3. Ações definidas (responsável + prazo)
4. Próximos passos
5. Tópicos pendentes para próxima reunião
```

## Exemplos Práticos

### Exemplo 1 – Resumo Executivo de Relatório Técnico

```
Tipo de documento: Relatório técnico de avaliação de segurança (Pentest)
Público-alvo do resumo: Executivo (CTO e Conselho)
Nível de detalhe: Alto nível (máximo 5 pontos)
Foco especial em: Riscos críticos e ações recomendadas

Resuma o relatório abaixo destacando apenas os riscos classificados como CRÍTICO ou ALTO, as recomendações mais urgentes e o impacto potencial para o negócio. Use linguagem não-técnica adequada para executivos:

[COLAR RELATÓRIO AQUI]
```

### Exemplo 2 – Ata de Reunião de Planejamento de Sprint

```
Contexto da reunião: Sprint Planning – Time de Desenvolvimento de Produto
Data: 27/04/2026
Duração: 2 horas
Participantes: Product Owner (Maria), Scrum Master (João), 5 desenvolvedores

Transcrição da reunião:
[COLAR TRANSCRIÇÃO AQUI]

Gere uma ata estruturada com:
1. Resumo executivo (3-5 linhas)
2. Histórias de usuário selecionadas para o sprint (com pontuação)
3. Decisões técnicas tomadas
4. Impedimentos identificados e responsáveis pela resolução
5. Compromissos do time para o sprint
```

### Exemplo 3 – Resumo Comparativo de Propostas Comerciais

```
Tipo de documento: 3 propostas comerciais de fornecedores diferentes
Público-alvo do resumo: Comitê de compras
Nível de detalhe: Médio (tabela comparativa + recomendação)
Foco especial em: Preço, prazo de entrega, garantias e diferenciais

Analise as 3 propostas abaixo e crie:
1. Uma tabela comparativa com os critérios principais
2. Um resumo dos pontos fortes e fracos de cada fornecedor
3. Uma recomendação justificada considerando o melhor custo-benefício

Proposta A:
[COLAR PROPOSTA A]

Proposta B:
[COLAR PROPOSTA B]

Proposta C:
[COLAR PROPOSTA C]
```

---

## Quando usar

- Para processar rapidamente documentos extensos antes de reuniões
- Para gerar atas estruturadas a partir de transcrições do Teams
- Para criar resumos executivos de relatórios técnicos
- Para comparar múltiplos documentos ou propostas de forma estruturada
